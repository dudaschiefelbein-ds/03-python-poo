# 📁 05: Python para Inteligência Artificial

Este módulo aborda os fundamentos de Inteligência Artificial e Aprendizado de Máquina, explorando algoritmos de agrupamento não supervisionado (Clusterização) e manipulação de tensores para processamento de dados em larga escala.

## 🧠 Conceitos Chave da Aula

*   **Agrupamento Não Supervisionado (K-Means):** Utilização da biblioteca Scikit-Learn para agrupar automaticamente objetos com características parecidas (neste caso, preço e peso de produtos) em grupos distintos (`clusters`), sem a necessidade de categorias pré-definidas.
*   **Manipulação de Tensores (TensorFlow):** Introdução à biblioteca principal de Deep Learning do Google. Demonstra como converter listas tradicionais em tensores constantes (`tf.constant`) para acelerar o processamento numérico, realizar cálculos de médias em matrizes (`tf.reduce_mean`) e aplicar máscaras lógicas (`tf.boolean_mask`) para filtragem rápida de dados.

## 🚀 Arquivos da Aula

*   **`01 - sci.py`**: Script de Machine Learning que utiliza dados estruturados de objetos de produtos, cria uma matriz do NumPy e aplica o modelo K-Means para separar e listar os produtos automaticamente em 4 grupos distintos de afinidade.
*   **`02- tensor.py`**: Código que simula dados de um e-commerce para demonstrar as operações essenciais da biblioteca TensorFlow, realizando o cálculo da média de preços e filtrando apenas os produtos pertencentes à categoria de eletrônicos através de máscaras de tensores.
