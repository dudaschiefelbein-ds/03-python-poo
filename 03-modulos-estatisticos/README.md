# 📁 03: Módulos Estatísticos e Visualização de Dados em Python

Este módulo aborda a introdução às bibliotecas mais utilizadas para o processamento numérico, manipulação de tabelas e geração de gráficos estatísticos no ecossistema do Python.

## 🧠 Conceitos Chave da Aula

*   **Processamento de Arrays (NumPy):** Demonstra como transformar coleções tradicionais do Python em estruturas numéricas de alta performance (arrays), facilitando o cálculo direto de métricas estatísticas sem a necessidade de criar laços manuais de repetição.
*   **Manipulação Tabular (Pandas):** Apresenta o conceito de DataFrames, que organizam listas e dicionários de dados em formato de tabelas estruturadas por linhas e colunas, permitindo ordenações e filtros rápidos baseados em valores específicos.
*   **Plotagem Visual (Matplotlib):** Mostra como traduzir conjuntos de dados numéricos em elementos visuais completos (como linhas e fatias de pizza), tornando mais fácil a análise e o entendimento de relatórios e métricas de desempenho.

## 🚀 Arquivos da Aula

*   **`01-libNumpy.py`**: Código que compara o cálculo tradicional de uma média aritmética (usando laço de repetição `for`) com o método automatizado `mean()` da biblioteca NumPy.
*   **`02-libPandas.py`**: Arquivo focado na criação de tabelas com dados populacionais de cidades, utilizando recursos para ordenar os dados em ordem decrescente e extrair apenas as primeiras linhas com o comando `.head()`.
*   **`03-libMat.py`**: Script que utiliza o componente de pizza do Matplotlib (`plt.pie`) para exibir de forma proporcional a quantidade e participação de fatias de mercado de diferentes navegadores web.
*   **`04-libMat.py`**: Exemplo completo de gráfico comparativo temporal que traça o comportamento de chamados abertos entre os setores de TI e RH ao longo dos meses, aplicando legendas, títulos e marcadores personalizados.
