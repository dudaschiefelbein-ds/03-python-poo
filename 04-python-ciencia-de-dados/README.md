# 📁04: Python para Ciência de Dados

Este módulo aplica os fundamentos de manipulação de dados, estatística e visualização em cenários práticos do mundo real, utilizando a Programação Orientada a Objetos para estruturar dados de saúde, finanças e marketing digital.

## 🧠 Conceitos Chave da Aula

*   **Modelagem de Dados Realistas:** Uso de classes Python clássicas para estruturar entidades reais (como Pacientes, Investimentos e Campanhas) antes de enviá-las para os ambientes de análise de dados.
*   **Conversão de Objetos para DataFrames (`from_records`):** Demonstração prática de como transformar listas de objetos/dicionários criados "na mão" em tabelas estruturadas do Pandas de forma automatizada, utilizando chaves personalizadas como índices.
*   **Cálculos Vetoriais e Lambdas (`.apply`):** Aplicação de funções anônimas para criar novas métricas coluna por coluna dentro de um DataFrame, como o cálculo de Índice de Massa Corporal (IMC) e fórmulas de juros compostos para retorno de investimentos.

## 🚀 Arquivos da Aula

*   **`01-saude.py`**: Script focado na área de saúde que transforma dados de objetos de pacientes em um DataFrame do Pandas. Utiliza funções matemáticas para calcular o IMC de cada indivíduo, além de aplicar filtros para descobrir a média geral e a porcentagem de pessoas com sobrepeso.
*   **`02- financas.py`**: Código voltado para análise financeira que calcula o retorno acumulado de diferentes ativos (como Ações e Tesouro Direto) usando fórmulas de juros compostos com base na taxa e período de tempo. Ao final, plota um gráfico de barras comparativo do retorno financeiro em reais.
*   **`03- marketing.p`**: Arquivo focado em métricas de marketing digital. Ele calcula o CPC (Custo por Clique) de diferentes canais de anúncios de forma orientada a objetos e utiliza o Matplotlib para gerar um gráfico de barras indicando quais plataformas entregaram o clique mais barato.
